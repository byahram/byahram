## Getting Started

**Requirements**

- Python 3
- NumPy, Pillow
- FFmpeg

저장소 루트에서 실행합니다. FFmpeg는 별도로 설치합니다.

**Installation**

```bash
pip install -r showcase/cherry-blossom/requirements.txt
```

**Run**

```bash
python showcase/cherry-blossom/cherry_blossom.py
```

**Output**

```text
showcase/cherry-blossom/output/cherry-blossom.mp4
```
