## Getting Started

**Requirements**

- Python 3
- NumPy, Pillow
- FFmpeg

저장소 루트에서 실행합니다. FFmpeg는 별도로 설치합니다.

**Installation**

```bash
pip install -r showcase/christmas/requirements.txt
```

**Run**

```bash
python showcase/christmas/christmas_tree.py
```

**With Photo (Optional)**

사진을 `showcase/christmas/private/me.jpg`에 넣고 실행합니다.

```bash
python showcase/christmas/christmas_tree.py --photo showcase/christmas/private/me.jpg
```

**Output**

```text
showcase/christmas/output/christmas-tree.mp4
```
