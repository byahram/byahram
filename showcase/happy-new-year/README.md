## Getting Started

**Requirements**

- Python 3
- NumPy, Pillow
- FFmpeg

저장소 루트에서 실행합니다. FFmpeg는 별도로 설치합니다.

**Installation**

```bash
pip install -r showcase/happy-new-year/requirements.txt
```

**Run**

```bash
python showcase/happy-new-year/happy_new_year.py
```

**Output**

```text
showcase/happy-new-year/output/happy-new-year.mp4
```
